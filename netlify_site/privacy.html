Privacy Policy

Household Manager · Last updated 8 September 2026

Household Manager is a private application used by the two members of a single household. It is not offered to the public and has no other users.

Google account data

The app requests one Google permission: calendar.events, which lets it read and write events on one shared Google Calendar chosen by the household. It uses this only to display that calendar inside the app and to add, change, or delete events when a household member asks it to.

The app stores an OAuth refresh token so it can keep accessing that calendar without repeated sign-ins. The token is held as an application secret and is not shared. Calendar events are read on demand and are not copied into the app's own database.

The app does not request access to Gmail, Drive, Contacts, or any other Google service, and it does not read any calendar other than the one configured.

Limited Use

Household Manager's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is used only to provide the features described above. It is not sold, not used for advertising, and not used to train any machine learning model.

Other information the app holds

Household content entered by its two users — checklists, grocery items, meal plans, notes, and reference entries such as contacts and appliance details — is stored in the household's own database.

Retention and deletion

Household content is kept until a household member deletes it. Google access can be revoked at any time from the Google account's third-party access settings, which immediately stops the app from reaching the calendar.
